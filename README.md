# Documentación de la API de Taxis

## Descripción
Esta API proporciona servicios similares a Uber para un servicio de taxis. Permite gestionar rutas, conductores, pasajeros, cobranzas y más.

## Requisitos
- Node.js
- PostgreSQL

## Instalación
1. Clona este repositorio.
2. Ejecuta `npm install` para instalar las dependencias.
3. Configura las variables de entorno en `.env`.
4. Ejecuta `npm run dev` para iniciar el servidor.
